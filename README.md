# The list

Every Claude Code plugin found in a public marketplace listing on GitHub, with what it does. 77,713 plugins, snapshot of 2026-09-21.

## Get it

- [`the-list.csv`](the-list.csv): everything in one file, for a spreadsheet or a script.
- [`the-list.md`](the-list.md): the same list as one document. Too big for GitHub to show; download it.
- [`list/`](list/): the same list in alphabetical pages that GitHub can show (index below).

## What is in it

- Source: 94,248 entries read from every `.claude-plugin/marketplace.json` the crawl found, including Anthropic's official, community and knowledge-work marketplaces.
- A plugin listed in several marketplaces appears once. Copies with the same name and description under other repos (forks, mirrors) are folded into the original, leaving 77,713.
- 75,424 have a description, in the author's own words, cut at 600 characters.
- 924 point at a repo that was already deleted or renamed at crawl time (`repo_gone` in the CSV).
- Plugins only. Standalone skills, hooks and commands that no marketplace lists are not here.
- Nothing here was reviewed or tested. Being listed is not a recommendation.

CSV columns: `name`, `description`, `category` (as the marketplace gave it, often blank), `repo`, `url`, `stars` and `license` and `last_pushed` (of the repo, not the plugin), `marketplaces` (how many list it), `copies` (how many identical entries were folded in), `repo_gone`.

Rebuild: `python3 build.py /path/to/signal.db`.
