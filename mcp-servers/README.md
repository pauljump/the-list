# MCP servers

2,586 MCP servers that people wire into Claude Code, read from 4,414 `.mcp.json` files.

## Get it

- [`mcp-servers.csv`](mcp-servers.csv) (0 MB)

Columns: `name`, `type`, `command`, `package`, `host`, `copies`, `example_repo`, `example_url`, `stars`.

## Notes

- One entry per server name and target (package or host). `copies` is how many configs use it, which is the closest thing here to a popularity count.
- Only the launcher, the package name and the host are kept. Arguments, environment variables, headers and URL paths are dropped because configs often carry keys.
- These files have no description field, so there is none here.
